    Enviar mensaje

    a la URL que indiques

    Pega la URL de tu compañero y le llega el cuerpo que todos aceptamos: { "name", "message" }. Si la URL no lleva ruta, se busca sola: primero /send-message/tu-nombre (lo que usa la mayoría en clase), luego /inbox, /mensajes y demás, y si el destino es una página web se lee su JavaScript para averiguar dónde escucha. Si ya sabes la ruta, escríbela y se usa esa: https://su-url.ngrok-free.dev/mensajes. El botón Probar te dice qué hay en la URL antes de enviar.
